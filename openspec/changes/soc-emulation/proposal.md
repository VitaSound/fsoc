# Proposal

## Why

`j1_prompt` рисует `ok` сам, без процессора и без образа в памяти. Нужна короткая прошивка, которую Forth-ассемблер J1 собирает в образ, и ядро J1, которое этот образ выполняет: байты `ok` в консоли — следствие исполнения. Сборка и запуск полноценной Forth-системы — следующий шаг после этого, не часть этого изменения.

## What Changes

- Новая задача `soc`. Рабочее решение — `projects/soc_emul` с коммитируемым `target.4th` (задача `soc`, таргет `emulation`, платы нет).
- `fsoc --build` из этого каталога собирает топ, прогоняет Forth-ассемблер, кладёт образ в `firmware.hex`, выгружает CSR и запускает Verilator до Ctrl+C.
- Ядро J1 читает образ из памяти и исполняет его. `j1_prompt` в этой задаче не используется.
- Прошивка по UART передаёт байты `o` и `k`. Консоль печатает их через `con_uart`. Каждый такт не печатается.
- Команды `fsoc soc` нет. Диспетчер по-прежнему берёт слово сборки из поля задачи.
- Проекта платы и запуска Quartus для SoC нет.
- Следующим шагом, отдельным изменением, будет сборка и запуск полноценной Forth-системы на этом ядре.

## Capabilities

### New Capabilities

- `soc`: задача SoC — топ из fhdlgen, ядро J1, прошивка из Forth-ассемблера, выгрузка CSR и эмуляция, в которой `ok` появляется из исполнения образа.

### Modified Capabilities

- Нет. Требования `builder` и `blinky` не меняются: билдер уже вызывает слово из `target.4th`, blinky канал `uart` не вызывает.

## Impact

- Новые: Forth-ассемблер J1 и исходник прошивки `ok`, ядро J1 и UART (вендор из swapforth, BSD), правка `cpu/j1/j1_wrap.v` так, чтобы оно исполняло `firmware.hex`, слово `soc-emit-emulation`, `designs/soc_top.4th`, `fsoc/soc_main.cpp`, `projects/soc_emul/target.4th`, тест.
- Без смены контракта: `fsoc/soc/csr.4th`, `fsoc/soc/cores.4th`, `firmware/hex2readmem.4th`, `emu/con`, `targets/emulation.4th`. `j1_prompt` остаётся только у своего Icarus-теста.
- `targets/base_soc.4th` перестаёт быть способом запуска SoC. Библиотечный тест CSR может остаться.
- README, AGENTS.md, doc/roadmap.md: этот шаг — `ok` из прошивки; следующий — полноценная Forth-система.
