# Proposal

## Why

Секция Hardware в логе `fsoc --build` печатает имена Verilog-файлов отдельной строкой, которая не связана с копированием. Добавленный лист в лог не попадает, пока строку не поправят руками. Такой отчёт врёт.

## What Changes

- Секция Hardware печатает пути include-verilog из фрагмента топа после разбора fhdlgen. Не из копирования в каталог проекта и не из обхода файлов.
- `top.v` называет шаг fhdlgen, а не общая строка рядом с ним.
- То же правило для секции Software: имя исходника печатает шаг, который его компилирует или подаёт в образ.
- Если источник имени в проекте не найден, литерал не пишется. Сборка такого списка не выдумывает: вопрос, откуда брать данные, задаётся до кода.

### Modified Capabilities

## Impact

- fhdlgen после разбора топа отдаёт пути элементов include-verilog. `fsoc` печатает их в секции Hardware. Литерал `verilog: stack2.v j1.v …` и печать из `soc-cp` уходят.
- Тест `fmix` проверяет, что в исходнике отчёта нет второго списка `.v`.
