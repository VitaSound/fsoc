## 1. Отчёт

- [x] 1.1 Собрать таблицу по списку `cpu:` для одного сценария консоли `1 2 + .`. Столбцы: профиль, MM, EX-C, CG, ширина клетки, байты образа, такты. Проверить: две строки `j1a` и `j1b`, тулчейн один, синтеза нет.
- [x] 1.2 Пустые такты не становятся чужими числами и не дают победителя. Разная ширина клетки не объявляет меньший hex лучшим. Проверить: при пустой колонке `j1b` победитель не печатается.
- [x] 1.3 Отчёт со строками разных тулчейнов синтеза не помечается сравнением ядер. Проверить: метка сравнения отсутствует.

## 2. Зависимость

- [x] 2.1 Колонка тактов `j1b` заполняется только после обёртки WIDTH 32 из изменения `forth-cross-layers`. До этого задача 1.1 обязана оставлять её пустой.
