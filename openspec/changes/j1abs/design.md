# Design

## Образ

`cpu-port` пустой значит id профиля. У `j1abs` порт `j1a`, поэтому `soc-port` отдаёт `j1a`: SwapForth, fsys kernel и обёртка `j1_wrap.v`. Комплект Verilog — `cpu/j1/j1abs/`. Листа нет в каталоге комплекта — ищется `cpu/j1/<port>/`.

## Таблицы

Чтение синхронное, иначе Yosys кладёт массив в LUT RAM. Адрес выставлен на такте N, данные действительны на N+1.

- `alu_rom` `512×32`. Адрес `{op[3:0], t, t_next, n, r, cin}`. Младшие биты: результат, перенос, совпадение бита. `2*` держит предыдущий бит T в переносе. `2/` берёт `t_next`.
- `ctrl_rom` `512×32`. Адрес `{kind[2:0], last, t_zero, insn[7], insn[6:4]}`. Данные: выбор PC, дельты стеков для не-ALU, импульсы записи, источник нового T.
- `stack_ram`: один массив `1024×16`, два порта. Данные в ячейках `0+dsp`, возвраты в `16+rsp`. Начальное значение `16'h55aa`.

В регистрах: PC, T, `dsp`, `rsp`, защёлка команды, номер бита, перенос, флаги сравнения. N и R защёлкиваются на такт после адреса стека.

Команда — 18 тактов: чтение стека, 16 бит с перекрытием, commit. На commit `code_addr` становится следующим PC, пишутся стеки и память. `io_rd` / `io_wr` / `mem_wr` длятся один такт.

## Проекты

- `blinky` + `cpu: j1abs`: fasm j1a пишет 0 и 1 в порт светодиода, harness baremetal.
- `soc` + `sys: fsys`: консоль j1a на этом ядре.
- `soc` + `lamp=1`: та же лампа, что `soc_blink`.
