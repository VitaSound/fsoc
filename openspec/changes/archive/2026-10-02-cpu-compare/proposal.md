# Proposal

## Why

Один и тот же сценарий на j1a и j1b нельзя сравнить по заметкам в CHANGELOG: там площадь одного фита, а не такты прошивки. Оба ядра — класс 0, одна Forth-инструкция за такт. Площадь кристалла сравнивать рано: второго прогнанного синтеза рядом нет.

## What Changes

- Отчёт по одной задаче и одному такту: для каждого `cpu:` — байты образа, ширина клетки, число тактов Verilator до конца сценария.
- Пара, которую можно назвать эффективнее по тактам: j1a и j1b. Строка другого EX-C в том же файле победителем не объявляется.
- Колонка тактов j1b пустая, пока нет 32-битной обёртки.
- Разбор LUT и Fmax в этот срез не входит.

## Capabilities

### New Capabilities

- `cpu-compare`: таблица тактов и размера образа для профилей одной задачи.

### Modified Capabilities

## Impact

- Читает манифест и поле `cpu:` из изменения `forth-cross-layers`.
- Не запускает Yosys и Quartus. Не пишет битстрим.
