## 1. Профили

- [x] 1.1 Слово `cpu:` в манифесте. Пустое поле у `soc` равно `j1a`. Неизвестный id останавливает сборку. Проверить: `soc_emul` без поля по-прежнему читает `j1a/nuc.fs`; `no-such-cpu` не запускает этот кросс.
- [x] 1.2 Записи `j1a`, `j1b`, `stm8`, `z80` с классом, FMAP, MM, EX-C, CG, BM. `stm8` и `z80` не собирают hex и не копируют `forth.asm`. Проверить: оба id останавливаются до `gforth`.

## 2. J1B

- [x] 2.1 Скопировать из `original/j1b` кросс и Verilog в `cpu/j1/swapforth/j1b/` и `cpu/j1/j1b.v`, не трогая `j1.v`. Положить текст BSD. Не копировать `src/j1b`. Проверить: `j1.v` содержит `WIDTH 16`, `j1b.v` содержит ширину 32.
- [x] 2.2 Пока нет обёртки WIDTH 32, `s" j1b" cpu:` останавливает сборку и не пишет образ j1a. Проверить: `firmware.hex` j1a не появляется в каталоге этой сборки.
