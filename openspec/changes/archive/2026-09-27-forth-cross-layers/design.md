# Design

## Context

`target:` в манифесте — тулчейн платы (`emulation`, `quartus`, `yosys`). Профиль `j1` в `frules/data/forth-fmap-profiles.json` — класс 0, `FMAP/j1: V-V-A-0-I`, CG=I, BM=C. `stm8ef` — класс 1, CG=E. `cerberus-z80` — класс 2, CG=F. Хост остаётся Gforth.

J1B Джеймса Боумана в [AFCK_J1B_FORTH](https://github.com/wzab/AFCK_J1B_FORTH), каталог `original/j1b`: клетка 32 бита, стеки глубины 32, инструкция по-прежнему 16 бит, UART `$1000` / `$2000`.

## Goals / Non-Goals

**Goals:**

- Профиль несёт строку FMAP, класс, MM, EX-C, CG, BM, ширину клетки и глубину стеков.
- Излучатель CG=I собирает образ j1a и j1b. CG=F и CG=E в этом срезе образ не собирают.
- HAL и слова приложения не выбирают ассемблер.

**Non-Goals:**

- Перенос `forth.asm`, `boardcore.inc` и e4thcom.
- Forth-ассемблер Z80 с рабочим hex.
- Плата AFCK, `src/j1b/*.vhd`, I2C, дамп через порт `$2345`.
- Общий набор мнемоник на три архитектуры.

## Decisions

1. Поле `cpu:` — id профиля. Пустое поле у задачи `soc` означает `j1a`, чтобы текущие проекты собирались без правки каждого `target.4th`.
2. CG=I — поля opcode без мнемоник CPU. CG=F — мнемоники словами. CG=E — вызов внешнего ассемблера. Задача не содержит этих трёх веток по имени `stm8` или `z80`: она вызывает излучатель, который зарегистрировал профиль.
3. j1a остаётся файлами, которые уже лежат в `cpu/j1/`. j1b кладётся рядом: `cpu/j1/swapforth/j1b/` (`cross.fs`, `basewords.fs`, `nuc.fs`, `swapforth.fs`) и `cpu/j1/j1b.v` плюс `stack.v` из `original/j1b/verilog/`. Модуль внутри файла может называться `j1`; имя файла — `j1b.v`, чтобы не затереть 16-битное ядро. Текст лицензии BSD Боумана копируется рядом.
4. Обёртка `j1_wrap.v` остаётся 16-битной. Для j1b нужна отдельная обёртка с WIDTH 32 и портом `mem_din`. Пока её нет, профиль j1b регистрируется, но сборка платы и эмуляции на нём останавливается с именем профиля, а не подставляет j1a.
5. UART j1b совпадает с картой `$1000` / `$2000`. `iomap` из-за смены профиля не переписывается.
6. Каталог frules ставит J1 в RP=0. Образ SwapForth отвечает `ok`, у j1b в ядре есть `depth`. Профиль записывает оси ISA и отдельно отмечает внешний интерпретатор. Одно не подменяет другое.
7. Каркас stm8 хранит ссылку на профиль `stm8ef` и не содержит исходников ядра. Каркас z80 хранит ссылку на профиль `cerberus-z80` и не содержит `asmz80.4th`.

## Risks / Trade-offs

- 32-битная клетка меняет индексацию RAM. Сравнение тактов j1b невозможно, пока нет обёртки. Это зафиксировано в изменении `cpu-compare`.
- Подстановка `j1a` при пустом `cpu:` скрывает развилку в старых манифестах. Явная запись `cpu:` в новых проектах обязательна в спеке сравнения.
