# Proposal

## Why

Сборка прошивки J1a зашита в `fsoc/tasks/soc.4th` и каталог `cpu/j1/swapforth/j1a/`. Смена машины (другое ядро J1, STM8, Z80) — не смена тулчейна платы. Оси FMAP из frules разделяют эти развилки: генерация кода у J1, STM8 и Z80 разная.

## What Changes

- Каталог профилей внутри fsoc. Поле манифеста `cpu:` называет профиль.
- Рабочие профили класса 0: `j1a` (уже в дереве) и `j1b` (Verilog и кросс из `original/j1b` репозитория wzab/AFCK_J1B_FORTH).
- Каркасы без образа: `stm8` (внешний ассемблер) и `z80` (Forth-ассемблер мнемониками).
- Диспетчер выбирает излучатель по коду CG, не по сравнению имени в задаче `soc`.

## Capabilities

### New Capabilities

- `forth-cross`: профили FMAP, поле `cpu:`, три вида излучателя кода.

### Modified Capabilities

## Impact

- `fsoc/tasks/soc.4th` перестаёт знать путь `j1a/` напрямую: путь даёт профиль.
- Новые файлы J1B не затирают `cpu/j1/j1.v`. Плата AFCK, VHDL и I2C из того репозитория не копируются.
- `forth.asm` из stm8ef не переносится.
