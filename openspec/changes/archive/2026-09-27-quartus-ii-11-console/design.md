# Design

## Context

Quartus II 11.1 (Build 173) на Windows открывает каталог `projects/soc_terasic_de0nano`. `--build` Quartus не запускает. Полный compile 2026-09-27 02:10:30 на `EP4CE22F17C6` прошёл без ошибок.

## Decisions

1. Длинная строка Verilog собирается обратно, пока `read-line` возвращает длину, равную буферу (127). Короткое чтение заканчивает строку. Чтение длины 0 после строки ровно в буфер — конец строки: Gforth не съедает перевод строки, если строка заполнила буфер. Пустые строки по-прежнему выбрасываются.
2. `VERILOG_INCLUDE_FILE` только для `` `include "имя" `` внутри листа. Префикс `` `include `` — 9 символов, кавычка — десятый. `s\"` в Gforth обрывается на неэкранированной кавычке, поэтому кавычка в искомую строку не входит.
3. `MISC_FILE` в Project Navigator Quartus II 11 не виден. `HEX_FILE` виден. Файл `$readmemh` — слово на строку, не Intel HEX. Два полных compile (02:03 и 02:10) оставили `INIT_FILE` у выведенного MIF, так что назначение `HEX_FILE` образ RAM не подменило. `$writememh` Quartus игнорирует (предупреждение 10175).
4. `USE_REGIO=0` — это `assign led = 1'b0`. Синтезатор не «выкинул регистр»: регистра не было. Консоль передаёт `USE_REGIO=1` и включает `rtl/regio.v`. Адрес — бит 10 шины `io`, в карте `$400` / `IO-LED`. Стек `io!` — `( n addr -- )`. Слово SwapForth `leds` (`4 io!`) пишет другой адрес.
5. Предупреждения 10230 на литералах без размера в `j1.v` и `uart.v` остаются. TimeQuest «not fully constrained» относится к задержкам портов: такт в `soc.sdc` задан, slack положительный.
