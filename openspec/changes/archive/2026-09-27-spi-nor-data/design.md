# Design

## Context

LiteX кладёт дополнительную флешку в регион `spiflash` и не делает её вектором сброса. Контроллер LiteSPI один; между чипами одного режима меняются константы. База классов лежит в `litespi/modules/generated_modules.py`. Текущий fsoc знает только битовый `io` J1 (`IO-LED` = `$400`).

## Goals / Non-Goals

**Goals:**

- Регион как данные: имя, начало, размер, режим `rw` или `ro`.
- Командное чтение SPI-NOR во внутреннюю RAM на Verilator.
- Один лист Verilog. Строка чипа задаёт opcode, dummy, число бит адреса, объём и страницу.

**Non-Goals:**

- Memory-map окно флешки. Это следующий срез.
- Загрузочная флешка, смена reset, деление flash конфигурации.
- Внешнее ОЗУ. Имя `main_ram` не получает шину.
- Quad, DDR, стирание и запись страниц.
- Генерация отдельного Verilog на каждый JEDEC.
- Привязка к пинам платы. Первый прогон — эмуляция.

## Decisions

1. Битовый `iomap` остаётся для LED, таймера и UART. Регион — соседняя запись, не замена бита.
2. Флешка этого среза не называется `rom` и не меняет адрес сброса J1a. Образ прошивки остаётся во внутренней RAM.
3. Интерфейс к Forth — команда «прочитать диапазон во внутренний буфер». Регистры команды сидят на текущей шине `io` как устройства карты, пока нет memory-map.
4. Лист `rtl/spi_nor.v` параметризуется opcode чтения, числом dummy-тактов, шириной адреса. Режим первого среза — 1-1-1.
5. Таблица чипов живёт в fsoc (`fsoc/soc/`). Первая строка копирует геометрию W25Q32JV: `device_id` `$7016`, объём 4194304 байт, страница 256. Команда чтения — `READ_1_1_1`, код `$03`, dummy-тактов 0. Поле `dummy_bits = 8` класса litespi на эту команду не переносится: оно не относится к коду `$03`.
6. Такт SPI на плате (`STARTUPE2`, `USRMCLK`, обычный вывод) — свойство платы, не строка чипа. В эмуляции такт — порт модуля.
7. Имя `main_ram` можно записать в список имён, которые регион не занимает под флешку. Размера и шины у него нет.

## Risks / Trade-offs

- Командные регистры на битовой шине `io` придётся сдвинуть, когда появится memory-map. Спека не закрепляет номера бит: их выбирает реализация и пишет в `iomap`.
- Модель флешки в Verilator должна отвечать на `$03`. Это модель теста, не микросхема на плате.
