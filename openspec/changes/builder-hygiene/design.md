# Design

## Context

См. proposal.md — Why. Все удаляемые единицы проверены `rg` по репозиторию: `j1-asm-ok`, `icarus-write-tb`, `verilator-write-sh` не вызываются; `soc-asm-include` грузит `ok.4th` и `j1asm.4th`, но их слова после перехода на кросс-компилятор SwapForth не используются. `j1_prompt.v` живёт только ради своего Icarus-теста. `firmware/firmware.hex` отслеживается git, хотя пишется сборкой.

## Goals / Non-Goals

**Goals:**

- Репозиторий содержит только то, что участвует в `fsoc --build`, `fsoc --load` или `fmix test`.
- OpenSpec отражает реальное состояние: завершённое — в архиве, открытое — в актуальном изменении.

**Non-Goals:**

- Любая правка поведения билдера, дизайнов, эмуляции.
- Переименования каталогов (`targets/`, `designs/`).

## Decisions

- **`soc-build-log` не архивируется, а закрывается.** Задачи 1.1 и 1.2 требуют печати путей из fhdlgen и из команд `soc-cross` / `soc-feed-file`; они переезжают в `design-out-contract`, где меняется контракт с fhdlgen. Спека `soc` уже содержит требование «Отчёт сборки называет генератор top.v», она остаётся. Альтернатива — доделать сейчас — тащит правку fhdlgen в гигиеническое изменение.
- **`fterm` и `midi_foot` остаются как заглушки.** Это заявленные цели ADR-0003 (host CSR bridge, MIDI foot controller). Удалять замысел не нужно; нужно перестать называть их готовыми. `fterm` получит реальный backend в `soc-board`.
- **`fjson` остаётся в зависимостях.** `builder-core` заменяет `fsoc-append` на `fjson.str-concat` и пишет `csr.json` через `fjson.emit-*`. Убирать и возвращать пакет через одно изменение бессмысленно.
- **`f` убирается.** Пакет даёт `fget`/`finclude` для theForthNet и не содержит строковых или файловых слов, нужных fsoc.

## Risks / Trade-offs

- [Удаление `j1_prompt_test` снижает число тестов] → тест проверял модель, которой нет в `top.v`; сеанс SwapForth в `soc_test` покрывает то же на реальном ядре.
- [`firmware.hex` в корне `firmware/` кто-то использовал вручную] → `projects/*/firmware.hex` пишется каждой сборкой; корневой файл не читается ни одним словом.

## Migration Plan

Один коммит на архив OpenSpec, один на удаление файлов и правку `package.4th`, один на документацию. Откат — `git revert` любого из них независимо.
