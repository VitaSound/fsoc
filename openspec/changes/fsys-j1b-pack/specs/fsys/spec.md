# Spec Delta

## ADDED Requirements

### Requirement: Хост j1b кладёт две команды в ячейку
Хостовый компилятор `fsys/host/cross.4th` MUST писать команду j1b в одно 16-битное полуслово и MUST двигать `here` на 2. Старшая половина ячейки MUST быть следующей командой, а не `nop`, когда за этой командой сразу компилируется ещё одна.

Слово с полем данных (`constant`, `create`, `variable`) MUST сохранить раскладку двух клеток: литерал в младшей половине своей ячейки и `$6000` в старшей, `exit` в следующей ячейке, данные по адресу `cfa + 2 cells`. Консольный компилятор цели MUST NOT меняться в этой смене.

`here` MUST оставаться строго меньше 16384. Иначе сборка MUST остановиться текстом `call out of range` и MUST NOT маскировать адрес вызова.

Образ j1a MUST NOT измениться: с `s" extra-min" s" 1" option:` строка размера MUST остаться `firmware.hex: 8008`.

#### Scenario: Две команды делят ячейку
- **WHEN** хост компилирует для j1b определение `: pack 1 2 + ;`
- **THEN** первые два полуслова тела — `8001` и `8002`, и второе не равно `6000`

#### Scenario: Константа держит exit в следующей ячейке
- **WHEN** хост компилирует для j1b `5 constant ka`
- **THEN** полуслово по `cfa` — `8005`, полуслово по `cfa + 2` — `6000`, полуслово по `cfa + 4` — `608c`

#### Scenario: Адрес вызова за пределом
- **WHEN** хост для j1b записывает `here` значением 16384
- **THEN** сборка останавливается, и текст ошибки содержит `call out of range`

#### Scenario: Образ j1a не сдвинулся
- **WHEN** манифест содержит `s" fsys" sys:`, `s" j1a" cpu:` и `s" extra-min" s" 1" option:`, и выполнен `fsoc --build`
- **THEN** в журнале есть строка `firmware.hex: 8008`

### Requirement: Хост j1b сворачивает чтение
Если предыдущая команда — вызов слова с телом «литерал + exit», а текущий токен — `@`, хост j1b MUST заменить вызов литералом и MUST дописать одну команду `[T]` (`6C00`). Литерал с установленным битом 15 MUST NOT сворачиваться. `@i` MUST остаться только у j1a.

Пары `dup @`, `2dup rshift` и `2dup lshift` MUST склеиваться в одну команду ALU только при ширине клетки 32. На j1a эти пары MUST NOT получать коды `$6C00`, `$0900` и `$0A00`.

Инлайн `!` MUST NOT выполняться: у `store` две команды ALU, и замена пары вызовов тремя слотами удлиняет образ.

#### Scenario: Чтение константы
- **WHEN** хост компилирует для j1b `5 constant ka` и `: rd ka @ ;`
- **THEN** тело `rd` — полуслова `8005` и `6C8C`

#### Scenario: Пара dup @
- **WHEN** хост компилирует для j1b `: da dup @ ;`
- **THEN** тело `da` — одно полуслово `6C9D`

#### Scenario: Запись остаётся вызовом
- **WHEN** хост компилирует для j1b переменную `vx` и `: sv vx ! ;`
- **THEN** тело `sv` занимает два полуслова: первое с кодом вызова, второе с кодом прыжка

## MODIFIED Requirements

### Requirement: Покрытие слоя не ниже 90 процентов
Каждый слой fsys MUST быть закрыт тестами так, что отчёт `fcov` по его файлам не ниже 90%. Порог MUST считаться отдельно для `fsys/fasm/j1a`, `fsys/fasm/j1b`, `fsys/kernel/j1a`, `fsys/kernel/j1b`, `fsys/common` и `fsys/host`. Среднее по слоям MUST NOT засчитываться. Сверка hex и строки `1 2 + .` MUST NOT заменять этот порог. Монолит SwapForth этим порогом MUST NOT измеряться.

#### Scenario: Отчёт по каждому слою
- **WHEN** после тестов слоя выполнен `fcov` по его каталогу
- **THEN** доля покрытия этого каталога не меньше 90, и провал одного каталога не закрывается высоким процентом другого
