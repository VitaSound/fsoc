## 1. Плата Altera

- [ ] 1.1 Прошить `soc.sof` на Terasic DE0-Nano из сборки Quartus II 11.1.
- [ ] 1.2 `gforth tools/fterm.4th <устройство>` и строка `1 2 + .` дают `3  ok`.
- [ ] 1.3 В hex `1 400 io!` зажигает пользовательский светодиод на `A15`, `0 400 io!` гасит его.

## 2. Сборка Xilinx

- [ ] 2.1 После закрытия раздела 1 добавить таргет Vivado отдельным файлом, плату разработки Xilinx на кристалле XCKU5P (пины из названного источника) и проект консоли `soc` с дизайном `designs/soc_console.4th`. `--build` пишет файлы проекта и не запускает синтез, если тулчейна нет. `USE_REGIO` остаётся 1.
