# spi-nor Specification

## Purpose

Один лист SPI NOR читает диапазон флешки командой во внутренний буфер. Строка чипа задаёт opcode, dummy-такты и ширину адреса; такт SPI задаёт плата или обвязка эмуляции.

## Requirements

### Requirement: Один лист Verilog на все чипы режима 1-1-1
Репозиторий MUST содержать один модуль `rtl/spi_nor.v`. Его параметры MUST включать код команды чтения, число dummy-тактов и число бит адреса. Сборка MUST NOT порождать отдельный Verilog на идентификатор JEDEC. Quad и DDR MUST NOT входить в этот модуль.

#### Scenario: Две строки таблицы, один модуль
- **WHEN** таблица содержит W25Q32JV и вторую строку с тем же режимом 1-1-1 и другим объёмом
- **THEN** в дереве один `rtl/spi_nor.v`, а отличия строк — поля таблицы, не второй файл модуля

### Requirement: Таблица чипов в fsoc
Таблица MUST жить в репозитории fsoc и MUST содержать для строки: имя, manufacturer id, device id, объём в байтах, размер страницы, opcode чтения 1-1-1, dummy-такты этой команды, число бит адреса. Первая строка MUST описывать W25Q32JV: device id `$7016`, объём 4194304, страница 256, opcode `$03`, dummy-тактов 0. Значение dummy 8 из класса litespi MUST NOT записываться в эту команду.

#### Scenario: Строка W25Q32JV
- **WHEN** таблица загружена и запрошено имя `w25q32jv`
- **THEN** device id равен `$7016`, объём равен 4194304, страница равна 256, opcode равен `$03`, dummy-тактов равен 0

### Requirement: Командное чтение во внутреннюю память
Эмуляция MUST дать Forth-образу прочитать непрерывный диапазон флешки во внутренний буфер RAM. Чтение MUST идти командой SPI, а не окном memory-map. Прогон MUST быть под Verilator и MUST NOT требовать плату. Образ прошивки MUST по-прежнему загружаться из `firmware.hex`, не с флешки.

#### Scenario: Блок из модели флешки
- **WHEN** модель SPI-NOR в тесте отвечает на команду `$03` байтами `AA BB`, и образ выполняет командное чтение двух байт с адреса 0 во внутренний буфер
- **THEN** буфер содержит `AA` и `BB`, а `firmware.hex` не читается контроллером флешки

### Requirement: Такт SPI не входит в строку чипа
Способ вывода такта (`STARTUPE2`, `USRMCLK` или обычный порт) MUST задаваться платой или обвязкой эмуляции. Строка чипа MUST NOT содержать имя примитива ПЛИС.

#### Scenario: Эмуляция с портом такта
- **WHEN** лист собран в эмуляции
- **THEN** у модуля есть порт такта SPI, и в `rtl/spi_nor.v` нет экземпляра `STARTUPE2` и `USRMCLK`
