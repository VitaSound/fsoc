# 8051 soft — R8051

Справка. Профиль `8051` в `fsoc/cpu.4th` (класс 1, FMAP `D-S-A-M-3-F`, MM=D, EX-C=S, CG=F, `cpu-ref` `at89c52`). Один `cpu:` на soft и hard; тело выбирает option `body` или default от `target:` (`emulation`/`yosys` → soft, `proteus` → hard). Soft пишет byte hex и поднимает Verilator/Yosys leaf. Hard — [at89c52-proteus.md](at89c52-proteus.md) (`projects/baremetal/blinky_8051` протестирован в Proteus).

Пустой `sys:` на задаче `soc` останавливается (`needs fsys`). `s" fsys" sys:` собирает `fsys/kernel/8051` и host cross. Консоль — ряд в `tests/con_core_test.4th`.

## Ядро

Исходник — [risclite/R8051](https://github.com/risclite/R8051) (Li Xinbing), Apache-2.0. В `cpu/8051/`: `r8051.v`, `instruction.v`, `LICENSE`/`NOTICE`, обёртки `top_blink.v`, `top_soc.v`, `top_fit.v`, UART из `cpu/j1/uart.v`. Память снаружи ядра: `CODE_BYTES` / `IRAM_BYTES` / `XRAM_BYTES` в `params.vh` (options `code` / `iram` / `xram`).

STC: `LCALL`/`RET`. TOS в `r2:r3`. Переменные ядра в XRAM от `$2000`. SCON/SBUF мостят buart; LED — `P1.0`.

## Проекты

| Проект | Задача | target | Заметка |
|--------|--------|--------|---------|
| `projects/baremetal/blinky_8051_emul` | blinky | emulation | fasm blink, pin LED |
| `projects/soc/soc_8051` | soc | emulation | fsys console |
| `projects/soc/soc_8051_blink` | soc | emulation | blink app на kernel |
| `projects/soc/soc_8051_colorlight` | soc | yosys | fit Colorlight 5A-75E v6.0 |

```bash
cd projects/baremetal/blinky_8051_emul
FSOC_EMU_CON=pin FSOC_EMU_EDGES=4 FSOC_EMU_FAST=1 fsoc --build

cd projects/soc/soc_8051
FSOC_EMU_FAST=1 FSOC_EMU_CON=term FSOC_EMU_UART_IN=$'1 2 + .\nwords\n' fsoc --build

cd projects/soc/soc_8051_colorlight
fsoc --build
```

Размеры (строки): `s" code" s" 8192" option:`, `s" xram" s" 1024" option:`. Fit-таблица: [j1-word-graph/soc-fit-8051.md](j1-word-graph/soc-fit-8051.md), команда `python3 doc/j1-word-graph/build.py fit-8051`. На LFE5U-25F образ blink (~4.3 КБ) не помещается в `code 4096`; `8192` / `16384` укладываются в 25 МГц (Fmax ~35–37 МГц).

## Ассемблер

`fsys/fasm/8051`. Part `at89c52` задаёт flash/IRAM defaults. Список `mcs-wl` на порядок поиска сам не встаёт.
