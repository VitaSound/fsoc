# Z80 — TV80 и хостовый fasm

Справка. Профиль `z80` в `fsoc/cpu.4th` (класс 2, FMAP `S-S-A-M-4-F`, CG=F, `cpu-ref` `cerberus-z80`, клетка 16 бит). Пустой `sys:` останавливается (`needs fsys`). `s" fsys" sys:` собирает консоль `fsys/kernel/z80` и пишет byte hex (две цифры на строку, 16384 байт). Проекты: `projects/baremetal/blinky_z80`, `projects/soc/soc_z80`, `projects/soc/soc_z80_blink`. Консоль — ряд в `tests/con_core_test.4th`.

## Ядро

Исходник — [hutch31/tv80](https://github.com/hutch31/tv80), Guy Hutchison, MIT. Verilog-порт T80 Даниэля Валльнера. В `cpu/z80/` лежат `tv80_alu.v`, `tv80_reg.v`, `tv80_mcode.v`, `tv80_core.v`, `tv80s.v`, `standalone.v`, `top_blink.v` и `top_soc.v`. Обёртка `tv80s`, параметр `Mode=0` (документированный Z80, не Fast Z80 / 8080 / Game Boy).

На выводы standalone выведены `clk`, `reset_n`, `wait_n`, `int_n`, `nmi_n`, `busrq_n`, `m1_n`, `mreq_n`, `iorq_n`, `rd_n`, `wr_n`, `rfsh_n`, `halt_n`, `busak_n`, `A[15:0]`, `di[7:0]`, `dout[7:0]`. Памяти, UART и таймера в standalone нет. `di` и `dout` не склеены в `inout`.

Soc: 16 КБ, I/O-страница `$3FF0..$3FF3` (LED, UART TX, UART RX, status). Очередь RX 128 байт. Двоеточие — STC (`CALL`/`RET`). Стеки Форта — указатели в RAM; SP — машинный возврат.

## Ассемблер

Хостовый fasm. Каталог `fsys/fasm/z80`. Сеанс тот же: `[asm]` … `[endasm]`, две проходки, метки. В ячейке образа один байт. Потолок — 65536 байт. Список слов `z80-wl` сам на порядок поиска не встаёт.

```forth
s" ../fsys/fasm/z80/fasm.4th" included
z80-wl >order
s" [asm] spin: spin jr, [endasm]" evaluate
```

Порядок операндов как в строке Intel, TOS справа: `b c ld,` — это `ld b,c`. Относительные `jr,` / `djnz,` считают смещение от следующей команды и останавливаются вне знакового байта. Поле 3 у `push,`/`pop,` — `af`, у `addhl,` / `ldw,` — `sp`.

## Стендэлон на ECP5

Проект `projects/standalone/standalone_z80`. Задача `standalone`, таргет `yosys`, плата `lfe5u25f_cabga256`: `clk` на `P6`, дальше голые шары.

Замер 2026-10-05, `synth_ecp5` и nextpnr, ограничение 25.00 МГц, маршрут сошёлся:

| Ресурс | z80 (TV80) | LFE5U-25F |
|--------|------------|-----------|
| LUT4 | 2276 (2114 логики, 90 переноса, 48 RAM, 24 RAMW) | 24288 |
| DFF | 240 | 24288 |
| DP16KD | 0 | 56 |
| TRELLIS_IO | 46 | 197 |
| Fmax | 69.74 МГц | 25.00 МГц |

```bash
cd projects/standalone/standalone_z80
fsoc --build
```

## Baremetal blink

Проект `projects/baremetal/blinky_z80`. Задача `blinky`, таргет `emulation`. Fasm собирает `firmware/blink_z80.4th` (OUT (0), A). `top_blink.v` держит 4 КБ RAM и светодиод на порту 0. Журнал: `cerberus-z80(z80)`, `image tool: fasm`, `firmware.hex: 11 bytes of 4096`.

```bash
cd projects/baremetal/blinky_z80
FSOC_EMU_EDGES=4 FSOC_EMU_FAST=1 FSOC_EMU_CON=pin fsoc --build
```

## Soc console

```bash
cd projects/soc/soc_z80
FSOC_EMU_CON=term fsoc --build
```

Консоль STC: TOS в DE, стек вниз от `DSP0`, TIB по `$3E00`. Accept/parse берут базу через `hl TIBA ldw` (не `hl@`). Сброс TOS при depth=1 — `zdrop` без `zpop` за `DSP0`. Имя в `header` копируется `djnz` по счётчику в B.

Blink на ядре: `projects/soc/soc_z80_blink`, `firmware/z80_blink.fs`.
